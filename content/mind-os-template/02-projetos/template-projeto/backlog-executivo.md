# Backlog Executivo — [NOME_DO_PROJETO]

> Backlog não é cemitério de ideias.  
> É fila priorizada de trabalho com vínculo explícito à arquitetura, às decisões e ao estado real do projeto.

---

## Regras
- Cada item deve apontar para o motivo de existir.
- Cada item deve indicar impacto, prioridade e critério de pronto.
- Itens sem critério de pronto são suspeitos.
- Itens sem vínculo com o norte do projeto tendem a ser ruído.

---

## Prioridades
- **P0** crítico, bloqueia sistema, segurança ou continuidade
- **P1** necessário para avanço da etapa
- **P2** importante, mas não bloqueante
- **P3** melhoria contextual
- **P4** expansivo/opcional
