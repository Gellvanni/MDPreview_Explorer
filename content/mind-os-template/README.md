# Mind OS Template

Pacote de arquivos `.md` para operar projetos com IA em workspaces que tenham:
- chat;
- arquivos;
- imagens;
- pastas;
- memória ou recuperação contextual.

## Estrutura

- `00-constituicao/` → identidade e instruções-base
- `01-modos/` → estados cognitivos reutilizáveis
- `02-projetos/template-projeto/` → memória viva de qualquer projeto
- `03-rituais/` → prompts/rituais de ativação prática

## Ordem mínima de uso

1. carregar `00-constituicao/nucleo-operacional.md`
2. carregar `00-constituicao/router-de-contexto.md`
3. duplicar `02-projetos/template-projeto/` para o nome do projeto real
4. preencher pelo menos:
   - `prancheta-mestra.md`
   - `sessao-atual.md`
   - `decisoes-congeladas.md`
   - `pendencias-riscos.md`
5. usar os rituais conforme a etapa
6. atualizar as memórias vivas ao final de cada sessão relevante

## Fórmula de uso

**núcleo operacional + router + prancheta + sessão atual + modo/ritual adequado + artefatos reais**

## Observação
Estes arquivos são genéricos por projeto, mas não genéricos por pensamento.  
Foram construídos para exigir profundidade, rastreabilidade e coerência estrutural.
