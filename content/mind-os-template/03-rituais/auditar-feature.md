# Ritual — Auditar Feature

> Use para avaliar uma funcionalidade específica depois de implementada ou prototipada.

---

## Prompt-base

Quero auditar esta feature como unidade de valor, não apenas como pedaço de código.

Analise:
- se a feature realmente resolve o problema que promete;
- se ela está coerente com o resto do sistema;
- se o usuário entende seu valor e seu funcionamento;
- se o custo estrutural está proporcional ao benefício;
- se ela introduz dívida, ruído ou duplicação de responsabilidade.

Devolva em sete blocos:

### 1. Valor prometido
### 2. Valor realmente entregue
### 3. Coerência com o sistema
### 4. Custo estrutural
### 5. Fricções percebidas
### 6. Ajustes recomendados
### 7. Veredito: manter, refinar, simplificar ou remover

---

## Uso recomendado
Acione quando uma feature parecer boa isoladamente, mas você ainda não souber se ela merece existir.
